# PROJECT STRUCTURE AND COMPONENTS

## Complete Project Structure Created

### Core Entities (Entity Layer)
- **Worker.java** - Represents waste management staff members
- **WorkerRole.java** - Enum for worker roles (CLEANER, DRIVER, HELPER, SUPERVISOR, MANAGER)
- **AttendanceRecord.java** - Records attendance events with face recognition confidence
- **AttendanceStatus.java** - Enum for attendance status (PRESENT, ABSENT, LATE, EARLY_LEAVE, ON_DUTY)
- **WasteTask.java** - Represents waste collection tasks
- **TaskStatus.java** - Enum for task status (PENDING, IN_PROGRESS, COMPLETED, CANCELLED, ON_HOLD)

### Repository Layer (Data Access)
- **WorkerRepository.java** - Database operations for workers
- **AttendanceRepository.java** - Database operations for attendance records
- **WasteTaskRepository.java** - Database operations for waste tasks

### Service Layer (Business Logic)
- **FaceRecognitionService.java** - Face detection and matching using OpenCV
  * Detect faces in images using Haar Cascade Classifier
  * Compare faces using histogram-based similarity
  * Verify workers from captured images
  * Camera frame capture support

- **AttendanceService.java** - Attendance processing
  * Record check-in with face verification
  * Record check-out with location tracking
  * Generate attendance reports
  * Calculate attendance statistics

- **WasteManagementService.java** - Waste task management
  * Create waste collection tasks
  * Assign workers and drivers to tasks
  * Track task completion with weight and location
  * Generate waste statistics

### Controller Layer (API Endpoints)
- **AttendanceController.java** - Attendance API endpoints
  * POST /api/attendance/checkin
  * POST /api/attendance/checkout
  * GET /api/attendance/status
  * GET /api/attendance/report
  * GET /api/attendance/worker/{workerId}

- **WasteManagementController.java** - Waste management API endpoints
  * POST /api/waste-tasks/create
  * POST /api/waste-tasks/{taskId}/assign-worker
  * POST /api/waste-tasks/{taskId}/assign-driver
  * POST /api/waste-tasks/{taskId}/complete
  * GET /api/waste-tasks/pending
  * GET /api/waste-tasks/in-progress
  * GET /api/waste-tasks/statistics
  * GET /api/waste-tasks/worker/{workerId}
  * POST /api/waste-tasks/{taskId}/cancel

- **WorkerController.java** - Worker management API endpoints
  * POST /api/workers/register
  * GET /api/workers/{workerId}
  * GET /api/workers/all
  * GET /api/workers/role/{role}
  * PUT /api/workers/{workerId}
  * DELETE /api/workers/{workerId}

### Data Transfer Objects (DTOs)
- **AttendanceDto.java** - Attendance response DTO
- **WasteTaskDto.java** - Waste task response DTO
- **WorkerDto.java** - Worker response DTO
- **ApiResponse.java** - Generic API response wrapper

### Configuration
- **HibernateConfig.java** - Hibernate ORM configuration and SessionFactory setup
- **hibernate.cfg.xml** - Hibernate database connection configuration
- **log4j2.xml** - Logging configuration

- **ValidationUtil.java** - Input validation utilities

- **CsvExporter.java** - Export utilities
